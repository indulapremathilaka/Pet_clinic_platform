# PetConnect Lanka — Pet Clinic Platform

Full-stack pet clinic platform for SE204.3 (Development of Enterprise Applications I).

**Active development happens on the `dev` branch** — that's where the full codebase (backend, frontend, docs) lives. This `main` branch is kept as the stable/release branch and will be updated via merges from `dev`.

See the `dev` branch for setup instructions, demo accounts, and the API reference.
